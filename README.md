# 🧠 React Quiz App

This is a simple quiz app built with **React** that uses the [Open Trivia Database API](https://opentdb.com/) to fetch multiple-choice questions.

## 🚀 Features
- Welcome form that collects your name, category, and difficulty
- Fetches quiz questions dynamically from the API
- Randomized multiple-choice answers
- Shows your result (correct or incorrect)
- Option to try again

## 🧩 Tech Used
- React (useState, useEffect, props)
- Open Trivia DB API
- CSS for styling
